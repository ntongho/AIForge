# AIForge

> **Building practical AI systems, one project at a time.**

AIForge is my growing collection of **practical AI engineering projects, experiments, and intelligent applications** built with open-source and free tools.

The goal is simple: **learn by building, solve real problems, and continuously improve.**

This repository documents my journey from Python and software engineering fundamentals to building applications powered by **LLMs, RAG, AI agents, machine learning, and other modern AI technologies.**

---

## 🎯 Mission

AIForge exists to turn knowledge into **working software**.

Rather than only following tutorials, I use each project to practice the engineering skills required to build real AI applications:

* 🐍 Python & software engineering

* 🗃️ Vector databases

* 🧪 Testing, debugging & evaluation
* 📊 Data processing and analysis

## 📈 Development Philosophy

Every project follows a simple cycle:

```text
Learn
  ↓
Plan
  ↓
Build
  ↓
Test
  ↓
Evaluate
  ↓
Improve
  ↓
Document
  ↓
Repeat
```

The objective isn't to build perfect software on the first attempt.

The objective is to **build, understand why it works, identify what doesn't, and improve it.**

---

## 🌱 Project Evolution

AIForge projects are designed to evolve.

A simple application may eventually become an AI-powered system.

For example:

```text
Basic Application
       ↓
API Integration
       ↓
AI/LLM Integration
       ↓
RAG
       ↓
Agents
       ↓
Evaluation
       ↓
Deployment
```

This allows each project to demonstrate not only the final result, but also the engineering process behind it.

## 💰 Free & Open-Source First

AIForge is being built with a **zero-budget mindset**.

Whenever possible, projects will use:

* Free software
* Open-source models
* Local AI models
* Free development environments
* Free hosting/deployment options
* Free APIs and services

Paid services may only be considered when absolutely necessary and when a suitable free alternative is unavailable.
