# Insight Engine

## Overview

**Version:** v0.1

Insight Engine is a text intelligence application that takes user input as text, counts the characters and words, finds the longest word, calculates the average word length, and displays the results.

## Features

* Accepts text input from the user
* Counts characters
* Counts words
* Finds the longest word
* Calculates average word length
* Handles empty input
* Displays the results in a simple format

## Technologies

* Python 3
* Python Standard Library

## How to Run

This project was built with Python 3.

From the project directory, run:

```bash
python3 src/main.py
```

## Example

```text
========================================
        INSIGHT ENGINE
========================================

Enter a piece of text:
Python is a programming language

--------------- INSIGHTS ---------------

Characters: 32
Words: 5
Longest Word: programming
Average Word Length: 5.3
```
